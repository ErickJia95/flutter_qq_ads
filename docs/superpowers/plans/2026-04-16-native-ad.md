# Native Ad Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Android and iOS self-rendered image-text native ad support without changing the existing template feed ad API.

**Architecture:** Keep `loadFeedAd + AdFeedWidget` untouched, and add a parallel native ad flow that returns `NativeAdData` plus a new `AdNativeWidget` PlatformView. Dart owns the API contract and example usage, while Android and iOS each own their own native ad loader, cache manager, and PlatformView binding to the Tencent SDK.

**Tech Stack:** Flutter, Dart, MethodChannel/EventChannel, Java, Objective-C, Tencent GDT SDK

```dart
@override
Future<List<NativeAdData>> loadNativeAd(
  String posId, {
  int width = 375,
  int height = 0,
  int count = 1,
}) async {
  final List<dynamic> result = await methodChannel.invokeMethod(
    'loadNativeAd',
    <String, dynamic>{
      'posId': posId,
      'width': width,
      'height': height,
      'count': count,
    },
  );
  return result
      .map((dynamic item) =>
          NativeAdData.fromJson(Map<String, dynamic>.from(item as Map)))
      .toList();
}

@override
Future<bool> clearNativeAd(List<int> list) async {
  final bool result = await methodChannel.invokeMethod(
    'clearNativeAd',
    <String, dynamic>{'list': list},
  );
  return result;
}
```

```java
public class NativeAdManager {
    private static NativeAdManager instance;
    private final Map<Integer, NativeUnifiedADData> nativeAdList = new HashMap<Integer, NativeUnifiedADData>();

    public static synchronized NativeAdManager getInstance() {
        if (instance == null) {
            instance = new NativeAdManager();
        }
        return instance;
    }

    public void putAd(int key, NativeUnifiedADData ad) {
        nativeAdList.put(key, ad);
    }

    public NativeUnifiedADData getAd(int key) {
        return nativeAdList.get(key);
    }

    public NativeUnifiedADData removeAd(int key) {
        return nativeAdList.remove(key);
    }
}
```

- [ ] **Step 3: Implement Android native ad loading with image-text filtering**

```java
public void onADLoaded(List<NativeUnifiedADData> list) {
    List<Map<String, Object>> adResultList = new ArrayList<Map<String, Object>>();
    for (NativeUnifiedADData adItem : list) {
        if (adItem == null || !adItem.isValid()) {
            continue;
        }
        if (adItem.getAdPatternType() == AdPatternType.NATIVE_VIDEO) {
            continue;
        }
        int key = adItem.hashCode();
        NativeAdManager.getInstance().putAd(key, adItem);
        adResultList.add(toNativeMap(key, adItem));
    }
    sendEvent(AdEventAction.onAdLoaded);
    result.success(adResultList);
}
```
